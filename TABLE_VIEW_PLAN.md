# Табличный вид списков — план

Большие наборы данных в ленте карточек читать неудобно. В списках появляется второй вид — таблица с основными
столбцами; пользователь переключается между лентой и таблицей.

Когда план выполнен — перенести суть в README и удалить файл.

## Где

| Список | Где в приложении |
| --- | --- |
| Мои заявки | «Заявки» |
| Заявки (все) | «Админ» → «Заявки» |
| Соревнования | «Соревнования» и «Админ» → «Соревнования» |
| Спортсмены | «Админ» → «Спортсмены» |

Справочник оружия пока остаётся компактным списком — вернуться к нему, когда посмотрим на таблицы в работе.

## Столбцы

На узком экране (телефон) видны основные столбцы, остальные появляются при большей ширине — без горизонтальной
прокрутки.

| Список | Всегда видны | Скрываются на узком экране |
| --- | --- | --- |
| Мои заявки | №, Соревнование, Статус | Сроки ЕКП |
| Заявки в «Админ» | №, Перевозчик, Статус | Соревнование, Сроки ЕКП |
| Соревнования | Даты, Название | Вид, Адрес |
| Спортсмены | ФИО, Статус | Перевозчик, Оружие (кол-во) |

## Поведение

- **Переключатель** — кнопка-иконка (☰ / ▦) справа над списком, в строке с поиском.
- **По умолчанию** — лента карточек.
- **Нажатие на строку** — полная карточка поверх таблицы со всеми кнопками действий (изменить, сменить статус,
  подтвердить и т.п.) — те же карточки, что в ленте.
- **Сортировка — нажатием на заголовок любого видимого столбца**: первое нажатие — по возрастанию, второе — по
  убыванию, третье — исходный порядок. Даты сравниваются как даты, № и количества — как числа, текст — по алфавиту.
  Отдельного выбора сортировки нет: по столбцу, скрытому на узком экране, сортируют на широком.
  Если экран стал уже (повернули телефон, сузили окно Telegram на компьютере) и столбец сортировки скрылся,
  сортировка сбрасывается (и в запомненном на устройстве) — список в исходном порядке. Так порядок всегда
  объясняется видимым заголовком со стрелкой.
- **Сортировка и поиск**: пока столбец не выбран, при поиске порядок — по похожести на запрос (как сейчас);
  выбранный столбец задаёт порядок и при поиске.
- **Фильтры** (статус, период, «Ждут подтверждения» и т.п.) работают и в таблице.
- **Порции**: сначала столько строк, сколько помещается на экран, дальше «Показать ещё (N)» — как в ленте
  (у строки таблицы своя высота, поэтому порция больше).
- **Запоминание**: вид и сортировка хранятся на устройстве (`localStorage`, с приставкой тестового окружения —
  `storageKey`) отдельно для каждого списка. Сохранённая сортировка по столбцу, которого больше нет, отбрасывается.

## Как сделано — готово

- `src/helpers.js`: `useListView(listId, columns)` — вид и сортировка с запоминанием на устройстве
  (`zns-list-view:<список>`), узкий экран — `matchMedia('(max-width: 520px)')`: при сужении столбцы `wide` скрываются,
  а сортировка по скрывшемуся столбцу сбрасывается (поэтому скрытие — в JavaScript, а не только CSS);
  `sortItems` — сортировка (пустые — в конце).
- `src/components.jsx`: `ListToolbar` (поиск + переключатель ☰ / ▦), `DataTable`, `CardModal`,
  `CardsOrTable` — лента или таблица с окном карточки.
- `src/listColumns.jsx` — наборы столбцов списков.
- Списки: «Мои заявки» (`my-applications`), «Соревнования» (`competitions`), в «Админ» — заявки
  (`admin-applications`), спортсмены (`admin-athletes`), соревнования (`admin-competitions`).
- Сортировка действует только в таблице; в ленте — прежний порядок.
